# MangoBD Agent Entry Point

**Start with [`CLAUDE.md`](CLAUDE.md).** The active product in this repo is **Mango Signal Map**, a client-facing 注意力设计与投放决策系统. The Mango BD system under `kol_database/` is the previous generation and is being retired — treat it as a parts source (real data worth inheriting, some code worth lifting), not as a running system to extend. `CLAUDE.md` covers what to salvage, which old constraints no longer apply, the four distinct "path" types that must never be merged, and the internal/client field isolation rules.

[`AGENTS.md`](AGENTS.md) remains the operating contract for source routing, evidence quality, and security. Its evidence contract still binds Signal Map.

[`PLAN.md`](PLAN.md) holds the old BD workstreams and is historical.

This compatibility entry point exists because the project owner requested `agent.md`; edit the canonical files rather than duplicating rules here.
